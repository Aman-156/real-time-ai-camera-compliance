# Real-Time AI Camera for Uniform & ID Compliance

An automated computer vision system designed to monitor, detect, and enforce campus or workplace uniform and ID card compliance in real-time.

## 🚀 Key Features
- **YOLOv8 Object Detection:** Detects individuals and ID cards.
- **DeepFace Integration:** Performs facial verification against a registered database.
- **Color Space Analysis:** Verifies institutional uniform colors.
